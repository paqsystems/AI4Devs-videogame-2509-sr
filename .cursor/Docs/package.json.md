# package.json

Archivo de configuración del proyecto Node.js que define las dependencias y scripts del proyecto.

## Descripción

Este archivo contiene la configuración del proyecto React para la aplicación "Barras de Número Montessori". Define las dependencias necesarias (React, ReactDOM) y las herramientas de desarrollo (Vite).

## Scripts Disponibles

- `npm run dev`: Inicia el servidor de desarrollo con Vite
- `npm run build`: Construye la aplicación para producción
- `npm run preview`: Previsualiza la build de producción

## Dependencias

### Producción
- `react`: ^18.2.0 - Biblioteca principal de React
- `react-dom`: ^18.2.0 - Renderizado de React en el DOM

### Desarrollo
- `@vitejs/plugin-react`: ^4.2.1 - Plugin de Vite para React
- `vite`: ^5.0.0 - Herramienta de construcción y servidor de desarrollo

## Notas

El proyecto utiliza Vite como herramienta de construcción por su rapidez y simplicidad. No requiere configuración adicional de Babel o Webpack.

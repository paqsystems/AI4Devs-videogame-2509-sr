# vite.config.js

Archivo de configuración de Vite para el proyecto React.

## Descripción

Configuración mínima de Vite que habilita el plugin de React para procesar archivos JSX y componentes React.

## Configuración

- **Plugin React**: Habilita el procesamiento de archivos JSX y componentes React
- **Modo desarrollo**: Hot Module Replacement (HMR) activado por defecto
- **Modo producción**: Optimización automática de assets

## Uso

Este archivo es procesado automáticamente por Vite cuando se ejecutan los scripts definidos en `package.json`. No requiere configuración adicional para el funcionamiento básico del proyecto.
